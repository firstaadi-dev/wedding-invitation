# Asal aset studi

Font: Inter oleh Rasmus Andersson, lisensi SIL Open Font License pada Inter-LICENSE.txt. Diunduh24 Oktober2026 melalui Google Fonts CSS family Inter400/500/600/700. Empat TTF dari fonts.gstatic.com/s/inter/v20/, masing-masing regular/medium/semibold/bold sesuai @font-face. CSS sumber: https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap . Lisensi dari https://raw.githubusercontent.com/rsms/inter/master/LICENSE.txt .

Ikon: SVG geometri ditulis langsung pada prototype.js untuk studi, viewBox24 dan stroke1,75. Tidak menggunakan foto, ilustrasi generatif, raster eksternal, atau aset invitation. Screenshot dalam ../screenshots/ adalah capture Chrome dari mockup lokal dengan data fiktif; bukan gambar generasi AI atau hasil Stitch.
