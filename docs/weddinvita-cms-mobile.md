# CMS weddinvita — tampilan mobile

Tampilan mobile mengikuti [desain CMS aktif](weddinvita-cms-results.md). Bukti pemeriksaan dan batasnya tercatat di [catatan implementasi](weddinvita-cms-implementation.md).

- Navigasi memakai drawer; login memakai hero dan form yang tersusun vertikal.
- Tamu tetap tabel, dengan kolom Nama dan WhatsApp terpisah. Tabel dapat digeser untuk melihat Salin link, Kirim, dan aksi lainnya.
- Filter mendapat lebar penuh; form dan kartu media tersusun satu kolom.
- Kontrol hadiah memakai pill ON/OFF ringkas; setiap informasi rekening/alamat memiliki kelompok field tersendiri.

Mockup mobile lama yang memakai kartu tamu dan satu field password sudah digantikan. Ekspor HTML/PNG serta halaman review lamanya dihapus dari repository.
